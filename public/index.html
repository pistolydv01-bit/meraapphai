InfinityFree Hosting Guide

InfinityFree पर इस Frontend App को Upload और Configure करने का बहुत ही आसान तरीका:

  1. InfinityFree Control Panel (cPanel) खोलें।
  2. File Manager पर जाएं और htdocs फोल्डर खोलें।
  3. पुराने सभी फाइल्स को हटाएँ या इस फ़ाइल का नाम index.html रखें।
  4. index.html को सीधे htdocs में अपलोड कर दें।
  5. अब आपकी वेबसाइट तैयार है! यह अपने आप आपकी Live Render Node.js API (https://app-admin-backend-1.onrender.com) से कनेक्ट हो जाएगी।
Note: Node.js बैकएंड पहले से Live Render पर चल रहा है। InfinityFree केवल इस HTML/JS Frontend UI को होस्ट करेगा, जो एकदम परफेक्ट काम करता है!
